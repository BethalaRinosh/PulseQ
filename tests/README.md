# Tests

Repeatable tests use Python's built-in `unittest`, so no third-party test dependency is required. Current unit-test modules cover patient records and linked-list operations, the routine FIFO queue, the emergency priority queue, and doctor registration/allocation. Search, sorting, CLI, and end-to-end tests will be added in their designated milestones.


Step 6 adds `test_doctors.py` for doctor validation, duplicate IDs, specialization matching, availability, load-aware allocation, duplicate patient assignments, release/reassignment, and clearing state.
