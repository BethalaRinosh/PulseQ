# Tests

Repeatable tests for the custom data structures, algorithms, patient operations, doctor allocation, and CLI validation will be added in the testing milestones. The intended test runner is Python's built-in `unittest`, so no third-party test dependency is required.


Step 6 adds `test_doctors.py` for doctor validation, duplicate IDs, specialization matching, availability, load-aware allocation, duplicate patient assignments, release/reassignment, and clearing state.
